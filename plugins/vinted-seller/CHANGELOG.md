## [0.1.0] - unreleased

### Added

- `listing` skill: German vinted.de listings from item photos; a folder of mixed photos is grouped into one listing per item after the user confirms the grouping.
- `post` skill (optional): fills the vinted.de upload form in the browser; the user publishes.
- `pricer` agent: price range from comparable vinted.de listings.
