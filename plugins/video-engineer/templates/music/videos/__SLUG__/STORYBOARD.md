# __SLUG__: storyboard

__W__x__H__, __FPS__ fps, __DURATION__ s (__TOTAL__ frames), __BPM__ BPM, one bar = __BAR__ s.
Song `public/audio/__SLUG__.mp3`, analysis `research/song.json`, word timings `research/alignment.json`, blocks `blocks.json`.

## Lyrics file

`videos/__SLUG__/lyrics.txt` is supplied by the user; the plugin never writes or reproduces lyrics. Format:

```
[INTRO]
(Ey, ey!)
[VERSE 1]
one sung line per text line, in sung order
[CHORUS]
...
[CHORUS]
...
```

- `[SECTION]` on its own line starts a section; every other non-empty line is one sung line. No comments or blank-line meaning.
- One block per section. A header that returns later (a second `[CHORUS]`) becomes the next block of that name (`chorus1`, `chorus2`).
- Ad-libs in parentheses on their own line.

## Global

- **Direction.** The chosen treatment from `research/directions.md`, verbatim: name, style frame (`research/choices/direction-<n>.png`), idea, world, device (how the lyrics live in the world, what the refrain becomes), form, signature block, and the Default line it departs from.
- **Palette.** Five values max, one table: name, hex, use. Fire/sky/skin rules go here.
- **Finish.** The `LOOK` id: `plain`, a project look in src/videos/<slug>/looks/, or a kit look the treatment names; texture, grain, bloom and glow come from it and the custom pieces. Depth of field and extra glow only where effects are allowed.
- **Custom pieces.** What this video adds beyond the kit, one line each: name, file (`src/videos/<slug>/looks/`, `fx/` or `blocks/<block>/`), what it does, which blocks use it. Glow, colour and texture outside the finish appear only here.
- **Effects.** `restrained` or `allowed` (from the treatment).
- **minTextPx.** Smallest lyric or headline text height in full-resolution pixels (default 48 at 1080p); the critic checks against it.
- **Materials.** Each element that must read as something real (water, fire, glass, sky, skin): what it must look like, and the reference still or plate it is built from. A procedural stand-in needs the lead's sign-off on a still.
- **Lyric typeface.** ONE family for every lyric in the video, the treatment's. Variety only by weight, size, colour, animation, layout. Diegetic UI (HUD, counters, tickers) may use its own fonts.
- **Lyric treatment.** Where the device puts the words in the world; free text with a soft dark shadow where they sit over the picture, no caption boxes. Boxes only where the world has them (sticker, post field). Unlit/past words stay at 38-55 % brightness or more.
- **Refrain.** What the refrain becomes in the treatment (written, carved, rolled, sung by a figure, extruded type with its materials); no ghost copies.
- **Music mapping.** `low` -> camera kicks, stamps; `mid` -> glow, scroll; `high` -> particles, jitter; `vocalOnsets` and word starts -> word entrances. Cuts sit on downbeats only.
- **Motion intensity** follows section energy; record the user's choices (for example "loud bridge: bright, chaotic, peaking") here, and update this file when a choice changes.
- **Shot rules.**
  - One shot per sung line (or two short lines), cut on a downbeat.
  - Max shot length 3.5-4 s. Longer only for a marked stillness where the music drops.
  - Each shot differs from its neighbours in subject, framing and UI.
  - In a 3D world: back = plate or set (parallax), mid = hero prop, fore = foreground element or UI (blurred, moves fastest). Name what sits at each depth in every shot. A flat world (a page, a table top, a screen) names its layers instead.
  - Safe area: text bottom >= 90 px above the frame edge; headlines fitted to measured width; no strobe over 3 full-frame white flashes per second.
